Vulkan Real‑Time Ray Tracing Renderer

2024 Graphics Programmer Vulkan + RTX Ray Tracing

Overview

A real‑time ray tracing renderer built using Vulkan’s RTX extensions, featuring BVH acceleration structures, physically‑based shading, soft shadows, reflections, and ray‑gen / closest‑hit / miss shader pipelines. The renderer demonstrates modern GPU ray tracing techniques and serves as a foundation for future hybrid raster‑RT engines.

My Responsibilities

  • Implemented TLAS/BLAS acceleration structures with Vulkan Ray Tracing extensions
  • Developed ray‑gen, closest‑hit, any‑hit, and miss shader stages
  • Built PBR shading with GGX, image‑based lighting, and HDR environment maps
  • Implemented soft shadows, reflections, and recursive ray evaluation
  • Created GPU pipelines for ray tracing, descriptor sets, and shader binding tables
  • Integrated real‑time debug visualizations for normals, depth, and BVH structure

Technical Highlights

  • Ray Tracing Pipeline: Ray‑gen, closest‑hit, miss shaders, SBT layout, recursion
  • Acceleration Structures: BLAS per mesh, TLAS per scene, GPU‑built BVH
  • Lighting: PBR materials, HDR IBL, GGX BRDF, environment sampling
  • Effects: Soft shadows, reflections, Fresnel, roughness‑based scattering
  • Debug Tools: BVH visualization, normal/depth buffers, ray debug views
  • Systems: Vulkan memory management, descriptor sets, GPU synchronization

Tech Stack

C++ Vulkan RTX Extensions GLSL PBR Shading BVH HDR IBL

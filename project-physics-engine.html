Physics Engine Demo

2024 Physics & Engine Programmer Custom Physics Simulation (C++)

Overview

A custom physics engine built from the ground up using Verlet integration, stick‑constraint models, and RK4 solvers. The system supports real‑time simulation, constraint resolution, collision handling, and interactive debugging tools. Designed for clarity, stability, and educational visualization, the engine demonstrates how physics systems behave under different numerical integrators.

My Responsibilities

  • Implemented Verlet integration for stable, constraint‑based motion
  • Built stick‑model constraints for ropes, cloth, and articulated bodies
  • Developed RK4 integrator for high‑accuracy rigid‑body simulation
  • Created IMGUI‑based debugging tools for visualizing forces, constraints, and solver iterations
  • Implemented collision detection and response for simple primitives
  • Designed modular physics subsystems for easy experimentation

Technical Highlights

  • Integrators: Verlet, Semi‑Implicit Euler, RK4
  • Constraint System: stick constraints, distance joints, iterative solvers
  • Simulation: stable particle systems, rope physics, cloth‑like behavior
  • Debug Tools: IMGUI overlays, constraint visualization, step‑through simulation
  • Collision: sphere, AABB, and plane collision tests
  • Architecture: modular physics loop with sub‑stepping and solver iterations

Tech Stack

C++ OpenGL GLSL IMGUI RK4 Verlet Integration Stick Constraints

Featured Components

Verlet Integration

Implemented Verlet integration for stable, constraint‑friendly motion. Ideal for rope, cloth, and soft‑body simulations where positional constraints must be solved iteratively.

Stick‑Model Constraints

Built a stick‑constraint system where particles maintain fixed distances, enabling rope physics, chain links, and articulated structures.

RK4 Solver

Added a Runge–Kutta 4th order integrator for high‑accuracy rigid‑body motion, allowing comparison between numerical methods.

Physics Debugging Tools

Created IMGUI‑based overlays to visualize constraints, forces, solver iterations, and simulation stability in real time.

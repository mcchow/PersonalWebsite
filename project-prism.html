Prism

Personal Game Engine C++ / OpenGL 2025

Overview

In Prism, players embark on a vibrant journey through color-coded challenges. Touching color collectibles changes the character's hue, and the goal is to navigate to the flag that matches the current color. Strategic thinking and quick reflexes are key to solving puzzles and advancing through increasingly tricky levels.

Game Engine Development

Utilized C++ and OpenGL to create a comprehensive game engine. Designed base component classes to manage game objects and logic, enabling users to develop their own games efficiently.

3D Rendering System

Built a robust rendering system that manages game object rendering using shaders and camera views. Enabled smooth 3D lighting and shadow effects for enhanced visual realism.

3D Physics System

Developed a 3D rigid body class supporting Oriented Bounding Box (OBB), Axis-Aligned Bounding Box (AABB), and sphere collision detection for accurate and efficient physics simulations.

Overview

A custom 3D engine featuring a modern rendering pipeline, real‑time animation system, editor tooling, and spatial audio. Designed to support stylized visuals, dynamic lighting, and efficient content workflows. GPU optimization achieved ‑18% GPU load and +22% FPS on RTX 3060.

My Responsibilities

  • Optimized GPU performance (‑18% GPU load, +22% FPS on RTX 3060)
  • Designed and implemented the rendering architecture (Deferred, GPU‑driven pipeline, Render Graph)
  • Built editor tools including material editor, spline/path editor, and real‑time debugging utilities
  • Developed the full animation pipeline: skeletal animation, blending, event system, and runtime retargeting
  • Integrated Bullet physics for collision testing and CCD
  • Created Unity‑to‑engine export pipeline for meshes, lights, paths, and gameplay metadata
  • Implemented 3D spatial audio with positional sound and attenuation

Technical Highlights

  • Pipelines: Unity → Engine exporter, custom asset formats, resource management
  • Rendering: Forward+, deferred lighting, cel‑shading, edge detection, GPU‑driven culling, Render Graph
  • Animation: Custom rig, blending, animation events, runtime retargeting
  • Tools: IMGUI‑based editor, asset import pipeline, debugging overlays
  • Physics: Bullet integration, CCD, collision visualization
  • Audio: 3D spatial audio system with real‑time mixing

Featured Components

Spline Editor

I created a custom spline editor that allows me to build and visualize splines directly inside the engine using IMGUI. The tool supports real‑time editing, point manipulation, and smooth curve visualization. To showcase the system, an animated running character follows the spline path, making it easy to test movement, timing, and animation blending.

Physics Engine Demo

I created a custom physics engine that allows me to build and visualize directly inside the engine using IMGUI. The system features physics simulation, rigid‑body dynamics, and numerical integration methods including Euler, Verlet, and Runge-Kutta for accurate motion prediction and collision response.

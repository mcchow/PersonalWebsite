Inverse Kinematics System

Animation Systems C++ / IMGUI 2024

Overview

A real-time inverse kinematics testing tool built on top of a custom spline editor. The project makes character posing and movement systems easy to inspect by combining interactive joint manipulation, selectable solvers, and animation path following inside the engine.

My Responsibilities

  • Implemented Cyclic Coordinate Descent (CCD) and Jacobian-based IK solvers
  • Built interactive controls for manipulating joints and testing end-effector targets
  • Integrated solver switching for comparing convergence and posing behavior in real time
  • Connected IK evaluation to spline path following and animation previews
  • Created IMGUI tooling to expose parameters and make iteration immediate

Technical Highlights

  • CCD Solver: Iteratively rotates joints from the end effector toward the root to reduce target error
  • Jacobian Solver: Uses the Jacobian relationship between joint motion and end-effector motion for responsive adjustment
  • Editor Workflow: Real-time controls make reachability, joint behavior, and solver differences visible while editing
  • Path Following: Spline-driven movement provides a practical test case for posing and animation blending

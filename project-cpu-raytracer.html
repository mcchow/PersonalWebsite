Juniper Engine – Color Puzzle World

2025 Engine & Tools Developer 3D Puzzle Game on Custom Engine (C++)

Overview

Color Puzzle World is a 3D puzzle adventure built on a custom engine featuring skeletal animation, dynamic lighting, Jolt physics, multithreaded systems, and Lua scripting. Players manipulate color to alter their character and interact with the environment — unlocking paths, activating mechanisms, and revealing hidden solutions. Each puzzle blends physics, light, motion, and script‑driven logic to reward experimentation and creative problem‑solving.

My Responsibilities

  • Implemented gameplay systems using Lua scripting for puzzle logic and interactions
  • Integrated Jolt physics for dynamic objects, triggers, and puzzle mechanisms
  • Developed animation and lighting features used throughout the game
  • Built multithreaded systems to support real‑time simulation and rendering
  • Created tools and workflows for designers to author puzzles and color‑based mechanics
  • Designed asset import/export pipelines for Blender models, materials, and scenes

Technical Highlights

  • Gameplay & Scripting: Lua‑driven puzzle logic, color‑based state system, scriptable triggers and mechanisms
  • Rendering: Dynamic lighting, stylized shading, real‑time material updates
  • Physics: Jolt‑based interactions, rigid‑body puzzles, collision‑driven events
  • Tools & Pipelines: Blender → Engine asset pipeline, scene import/export, designer‑friendly puzzle authoring tools
  • Systems: Multithreaded update loops, engine subsystems for gameplay, physics, and rendering

Tech Stack

C++ Lua OpenGL GLSL Jolt Physics IMGUI Blender (Assets)

Featured Components

Color‑Based Puzzle System

Designed a flexible color‑state system where player abilities, object behaviors, and puzzle logic all respond to color changes. This system drives doors, platforms, triggers, and environmental interactions.

Lua Gameplay Scripting

Built a Lua scripting layer enabling designers to define puzzle logic, triggers, animations, and object behaviors without modifying engine code.

Physics‑Driven Interactions

Integrated Jolt physics to support dynamic objects, rigid‑body puzzles, collision events, and interactive mechanisms.

Blender Asset Pipeline

Created a Blender‑to‑engine pipeline for meshes, materials, animations, and scene metadata, enabling fast iteration for designers.
